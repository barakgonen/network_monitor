Notes

UDP/TCP messages are described straight from each interface's serdes/*.protocol.json file - no reflection, no Java class needed. REST operations are described from the interface's swagger/*.yml file. Nested/complex fields are grouped visually by their dotted path (e.g. header.msgType); array-of-struct fields get an "add row" control. Leave Host/Port blank to fall back to the interface's own configured port on localhost. "Start Periodic" schedules a repeating send and switches you to the Periodic Jobs tab - multiple concurrent jobs are supported, even for the same message with different targets.

Periodic Jobs

Every "Start Periodic" click creates an independent job, identified by a generated id - stopping one doesn't affect the others. Job state is in-memory only and lost on restart.
